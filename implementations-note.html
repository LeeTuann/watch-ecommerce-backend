E-Commerce Backend Implementation Notes

Running log of engineering decisions, spec deviations, and architectural tradeoffs.

1. Initial Setup

Decision
Constructor-based Dependency Injection
Instead of using @Autowired on fields, we are utilizing constructor-based dependency injection across all service implementations. This is the modern, recommended pattern for Spring Boot as it enables immutability, cleaner unit testing, and clearer dependency tracking.
Change / Fix
Cart / Card Naming Alignment
The specification mentions CardResponse.java and CardItemResponse.java under the DTO directory. These are typographical variants of CartResponse and CartItemResponse. To respect the existing codebase files without breaking the structural expectations, we will preserve the exact CardResponse and CardItemResponse class names in the mapper and controller layer, while correctly associating them with the Cart and CartItem database entities.
Decision
Automatic Cart Initialization on Registration
When a new user registers through AuthService.register, we proactively instantiate and persist an empty Cart entity linked to their account. This safeguards the system against null pointer exceptions and ensures a seamless experience when they interact with the shopping cart API endpoints immediately after signing up.
Decision
Password Protection and BCrypt Hashing
All user passwords are automatically hashed using BCryptPasswordEncoder prior to database persistence. This is implemented in both AuthServiceImpl.register and UserServiceImpl.updateUser to ensure security compliance.
Decision
Atomic Stock Reservation on Checkout
During the order creation process (checkout), we validate that every selected product has enough stock. If stock is available, we atomically decrement it before saving the order. If any item fails validation, the entire transaction is rolled back.
Decision
Automatic Inventory Restoration on Cancellation
When an order is cancelled via OrderService.cancelOrder, we automatically restore the exact quantities of all ordered items back to the product catalog, helping maintain accurate inventory counts.
